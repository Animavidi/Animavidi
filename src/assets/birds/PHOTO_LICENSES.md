# Bird photography attribution

The photographs identified in `photo-credits.json` retain their individual Creative Commons licences. These licences apply to the listed image assets and their image derivatives, independently of the application source-code licence.

Each record identifies the original Commons description page, credited photographer, selected licence and licence URL, original download URL/checksum, optimized file checksum and resizing/conversion performed. The source images were reviewed on 29 October 2026. The application displays attribution on species detail pages and in its Photo Credits gallery, linked from shared footers.

The WebP image derivatives are offered under the same licence recorded for the source image. The originals remain available through their source pages. Displayed crops may vary with the responsive layout. Existing user photographs are preserved separately.
